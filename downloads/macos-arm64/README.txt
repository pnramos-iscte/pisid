PISID Maze para macOS Apple Silicon

Obtém o pacote através da área reservada indicada pelo docente e segue o guia:
https://pnramos-iscte.github.io/pisid/guia-instalacao.html

O pymaze é o simulador/servidor fornecido pela UC.
O pyplayer é apenas uma ferramenta visual opcional para compreender a
simulação. Não deve ser incorporado no trabalho: cada grupo tem de desenvolver
o seu próprio jogador/software.
