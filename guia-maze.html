Executar o Maze Simulator

Escolhe o player e aquilo que queres observar. O assistente constrói o comando correto para copiares para o terminal.

Construir o meu comando

O único dado obrigatório é o player. As restantes escolhas só aparecem no comando quando alteram o funcionamento normal.

1Qual é o teu player?
Obrigatório. Atualmente pode ser de 1 a 40.
2Queres usar MQTT?
Não é acrescentada nenhuma opção: MQTT fica ligado.
3O que queres ver no terminal?
Ou escreve ALL para todas.
Opções avançadas: substituir temporariamente o broker MQTT

Normalmente não precisas de preencher nada aqui. A ligação à base de dados da UC já vem configurada no executável.

Só deves alterar este valor num teste explicitamente orientado pelo docente.
Comando pronto

Exemplos frequentes

Podes copiar diretamente ou reproduzir a escolha no assistente.

Funcionamento normal

./pymaze 1

Ver tudo

./pymaze 1 --log-level 3 --log-categories ALL

Só temperatura

./pymaze 1 --log-level 2 --log-categories TEMPERATURE

Teste sem MQTT

./pymaze 1 --no-mqtt

Referência das opções

Estas são todas as opções que um aluno pode escrever na linha de comando. Abre apenas a que precisares.

Importante: o executável já contém a configuração necessária para contactar o servidor da UC. Não tens de indicar servidor, utilizador ou palavra-passe. O pyplayer fornecido é apenas uma visualização opcional; o grupo tem de desenvolver o seu próprio jogador.
