Maze Simulator

Guia de instalação

Os programas são fornecidos já compilados. Não precisas de instalar Python, bibliotecas nem configurar a ligação à base de dados da UC.

Windows 64 bitsDisponível através do docente · ver instruçõesmacOS · Apple SiliconProcessadores M1, M2, M3, M4… · ver instruções

pymaze · necessário

É o simulador/servidor fornecido pela UC. Cria a simulação, produz os dados dos sensores e comunica através dos mecanismos previstos no enunciado. É este programa que deves executar para testar o trabalho do grupo.

pyplayer · extra opcional

É apenas uma ferramenta visual para ajudar a perceber o que o servidor está a fazer. Não deve ser incorporado, adaptado ou apresentado como parte do trabalho. Uma parte central do projeto é precisamente o grupo desenvolver o seu próprio jogador/software.

Não confundas os dois programas. O pymaze simula o mundo com que o trabalho comunica. O pyplayer fornecido é apenas uma referência visual opcional. A solução do grupo tem de implementar o seu próprio jogador.

WINInstalar no Windows 64 bits

1

Obter e extrair o pacote

Obtém junto do docente o ficheiro PISID-Maze-Windows-x64.zip. Clica nele com o botão direito, escolhe Extrair tudo… e abre a pasta criada. Não executes os programas diretamente de dentro do ZIP.

2

Ligar a VPN quando necessário

Se estiveres fora da rede do ISCTE, liga primeiro a VPN GlobalProtect. Sem a VPN, a ligação ao servidor poderá terminar com a mensagem Can't connect to MySQL server ou timed out.

3

Abrir o PowerShell na pasta

No Explorador de Ficheiros, abre a pasta extraída. Clica na barra onde aparece o caminho da pasta, escreve powershell e carrega em Enter.

4

Executar o simulador

Substitui 10 pelo número do jogador atribuído ao grupo:

.\pymaze.exe 10

Mantém esta janela aberta. Para interromper manualmente o simulador, usa Control + C.

5

Opcional: observar com o pyplayer

Abre uma segunda janela PowerShell na mesma pasta e executa:

.\pyplayer.exe 10

Usa o mesmo número. O pyplayer serve apenas para observar e não substitui o software do grupo.

6

Se o Windows bloquear

Se aparecer “O Windows protegeu o PC”, e obtiveste o pacote através da área oficial indicada pelo docente, escolhe Mais informações → Executar mesmo assim. Não ignores este aviso em ficheiros recebidos por email, chat ou fontes desconhecidas.

7

Problemas frequentes

  • Se houver timeout, confirma a VPN GlobalProtect.
  • Se faltar uma DLL, instala o Microsoft Visual C++ Redistributable x64.
  • Ao pedir ajuda, copia a mensagem completa do PowerShell.

MACInstalar no macOS Apple Silicon

1

Confirmar o tipo de Mac

Abre o menu  → Acerca deste Mac. Estas instruções destinam-se a computadores com processador Apple M1, M2, M3, M4 ou posterior.

2

Obter o pacote

Obtém junto do docente, através da área reservada indicada nas aulas, o ficheiro PISID-Maze-macOS-ARM64.zip. Por segurança, os executáveis não estão disponíveis neste site público. Guarda o ZIP, por exemplo, na pasta Descargas.

3

Descompactar

No Finder, faz duplo clique no ficheiro ZIP. Será criada a pasta PISID-Maze-macOS-ARM64, com os programas pymaze e pyplayer e um ficheiro de instruções.

4

Abrir o Terminal na pasta

Abre a aplicação Terminal. Escreve cd seguido de um espaço, arrasta a pasta extraída do Finder para a janela do Terminal e carrega em Enter. O macOS preencherá o caminho por ti.

5

Autorizar os executáveis

Na primeira utilização, copia estes dois comandos para o Terminal:

chmod +x pymaze pyplayerxattr -dr com.apple.quarantine pymaze pyplayer

Estes comandos só tornam executáveis os dois ficheiros descarregados e removem o bloqueio de quarentena do macOS nessa pasta.

6

Executar o simulador

Substitui 10 pelo número do jogador atribuído ao grupo:

./pymaze 10

Deixa esta janela aberta durante a simulação. Para terminar manualmente, usa Control + C.

7

Opcional: observar com o pyplayer

Abre uma segunda janela do Terminal, entra na mesma pasta e executa:

./pyplayer 10

Usa exatamente o mesmo número do jogador. Este ecrã serve apenas para compreender e observar a simulação; não substitui o software que o grupo tem de desenvolver.

8

Se algo não funcionar

  • Confirma que descarregaste a versão adequada ao processador.
  • Confirma que o Terminal está dentro da pasta extraída.
  • Confirma que escreveste ./ antes do nome do programa.
  • Confirma que tens ligação à rede necessária para chegar ao servidor da UC.
  • Copia a mensagem completa do Terminal quando pedires ajuda.

Para opções de logging e testes específicos, consulta o guia interativo do Maze.
