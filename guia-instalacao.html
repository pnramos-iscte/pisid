Maze Simulator

Guia de instalação

Este guia ficará associado aos pacotes finais de pymaze e pyplayer. Os executáveis serão fornecidos já compilados para cada sistema operativo.

Os executáveis ainda não estão disponíveis. Quando forem publicados, descarrega apenas o pacote correspondente ao teu computador.
Windows 64 bitsFicheiro ZIP
macOS Apple SiliconProcessadores M1, M2, M3, M4…
macOS IntelComputadores Mac com processador Intel
1

Descarregar

Na página inicial, escolhe a versão do teu sistema operativo e guarda o ficheiro numa pasta de trabalho.

2

Descompactar

Extrai todo o conteúdo do ZIP. Mantém pymaze e pyplayer juntamente com os restantes ficheiros incluídos no pacote.

3

Autorizar no macOS

Na primeira execução, o macOS pode bloquear uma aplicação descarregada da Internet. Em Definições do Sistema → Privacidade e Segurança, confirma que pretendes abri-la. As instruções exatas serão ajustadas depois de testarmos os pacotes finais.

4

Executar no terminal

Abre um terminal na pasta extraída e segue o guia interativo do Maze para construir o comando. A ligação ao servidor da universidade já estará configurada.
